# Endterm қорғауына дайындық

Қорғау кезінде AI-дан да, басқа адамнан да көмек сұрауға болмайды. Тек ресми құжаттама мен w3schools.

## Файлдар картасы

- **Жай JavaScript:** `main.js` (footer: ашық/жабық + іздеу), `services.js` (каталог + estimate), `booking.js` (негізгі форма), `register.js`, `login.js`, `forms.js` (ортақ валидация), `dom.js`, `account.js` (парольді көрсету).
- **jQuery:** `jq-reviews.js`, `jq-help.js`, `jq-specialists.js`, `jq-profile.js`, `jq-common.js`.
- **Ортақ таза функциялар:** `utils.js` (DOM-ға тиіспейді), деректер — `data.js`.
- Бір функция не жай JS, не jQuery. Екеуі бір файлда араласпайды.

## Көрсететін сценарийлер

1. **Footer:** `getOpenStatus` — `HOURS` объектісінен «ашық / қазір жабық / бүгін жабық / сенбі келісім бойынша» шығарады. Қазақстан уақыты (`Asia/Almaty`).
2. **Services:** карточкалар `SERVICES` массивінен цикл арқылы жасалады (HTML-де жоқ). Сүзгіні өзгертсеңіз карточкалар қайта жасалады, бірақ «Add to estimate» жұмыс істей береді — бұл **delegation**: тыңдаушы `grid`-те тұр, ол жойылмайды, ал басылған батырманы `event.target.closest(...)` табады.
3. **Booking:** бос форманы жіберіңіз → әр өрістің қасында қате. Түзетсеңіз қате бірден кетеді. Жексенбіні таңдаңыз → қате. Дұрыс деректер → растау, форма тазарады.
4. **Register → Login → Profile:** тіркелу, кіру (қате пароль → қате), профильде мәліметтер мен сұраныстар тізімі, Edit, Log out.
5. **Reviews / Help / Specialists:** сүзгі, FAQ слайды, карта табы, баға кестесін тақырыпты басып сұрыптау.

## Сұрақтарға дайын жауаптар

- **Delegated handler неге жаңа элементтерді ұстайды?** Оқиға (click) элементтен жоғары ата-анаға көтеріледі (bubbling). Тыңдаушы ата-анада тұр, ал `event.target` — басылған нақты элемент. Сондықтан кейін жасалған батырмалар да ұсталады.
- **`preventDefault()` не істейді?** Формаға браузердің әдепкі әрекетін (GET жіберу, бетті қайта жүктеу) тоқтатады — біз өз тексеруімізді жасаймыз.
- **Жолды алып тастасаңыз не бұзылады?** Мысалы, `form.reset()` алдында қорытындыны жинамасаңыз — мәтін бос болады; `replaceChildren()` болмаса тізім қайталанып жинала береді.
- **Неге `trim()`?** Бос орындармен енгізілген «   » мәнін дұрыс деп қабылдамау үшін.
- **jQuery → plain JS:** `$('#id')` → `document.getElementById`, `.on('click', sel, fn)` → `addEventListener` + `event.target.closest(sel)`, `.addClass` → `classList.add`, `.text()` → `textContent`, `.find()` → `querySelector`, `.closest()` → `closest()`, `.siblings()` → `parent.children` сүзгісі.
- **Chain (3+ әдіс):** `jqShow` ішінде `.stop().text().removeClass().hide().fadeIn()`; FAQ-та `.siblings().find().slideUp()`.
- **Қарапайым JS және jQuery неге бөлек?** Бір функцияны екі тәсілмен басқарсаң, екі тыңдаушы бір элементке қатар жұмыс істеп, қайшылық шығады.

## Қорғауда тапсырма берілсе

- Валидацияға өріс қосу: `booking.js` ішіндегі `fields` массивіне `{id, check}` қосу.
- Цикл не жасайтынын өзгерту: `services.js` ішіндегі `buildCard`.
- Батырмаға тағы бір әрекет: `grid.addEventListener('click', ...)` ішіне жол қосу.
- jQuery-ді жай JS-ке жазу: `jq-help.js` ішіндегі `$faq.on('click', '.accordion-button', ...)` кішкентай блогы.
