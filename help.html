How this site was built

This website was built as part of Assignment 1 of the "Introduction to Web Technologies" course. Pure HTML5 was used for the structure and markup. As required by the assignment, no CSS stylesheet and no JavaScript were used — the site consists entirely of unstyled, semantic markup.

Visual Studio Code was used to write the code, and Google Chrome was used to check the files locally. Planning the semantic structure, writing the content and validating it took about 6 hours. Code quality was checked with the W3C Markup Validation Service, and every error was fixed. Git was used for version control, with all changes saved through proper commits.

Example: opening the file in a browser
