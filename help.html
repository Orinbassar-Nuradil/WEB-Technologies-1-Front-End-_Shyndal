How this site was built

This website started as Assignment 1, in pure semantic HTML5 with no CSS or JavaScript. Assignment 2 added a hand-written stylesheet. Assignment 3 (this version) rebuilds the layout on Bootstrap 5.3.3 — see the comment at the top of css/base.css for the version and why.

Visual Studio Code was used to write the code, and Google Chrome was used to check the files locally. Git was used for version control, with all changes saved through proper commits.

Example: opening the file in a browser

Type the following command in the terminal:

open index.html

You can also open the file manually by pressing Ctrl + O.
